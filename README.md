## 🌟 قابلیت‌ها

- 👥 مدیریت کاربران با حجم، زمان و درخواست مجاز
- 🔌 کنترل اتصال همزمان
- 🛡 بایپس فیلترینگ با Fragment و Fingerprint
- 📡 دریافت خودکار Clean IP
- 📊 مانیتورینگ زنده مصرف
- 🔄 آپدیت خودکار از داخل پنل
- 🔗 لینک‌های اشتراک VLESS
- 🗄 دیتابیس D1 کلودفلر
- 📱 رابط کاربری مدرن با Dark Mode

---

## 🚀 نصب

1. کد `zeus.js` رو از این ریپو دانلود کنید
2. در Cloudflare Worker جدید پیست کنید
3. تنظیمات D1 و KV رو اضافه کنید
4. پنل آماده است!

## 📝 تغییرات نسبت به نسخه اصلی

- ✅ حذف لینک‌های اشتراک تبلیغاتی
